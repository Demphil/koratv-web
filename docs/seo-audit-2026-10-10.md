# Search visibility audit, 2026-10-10

## Verified public behavior

- Both HTTPS homepages, news pages, robots.txt and sitemaps return HTTP 200 without a noindex response header. Root canonicals point to the correct domain. Unknown paths return HTTP 404 with noindex.
- A request carrying a Googlebot User-Agent receives indexable HTML on both hosts. This does not establish whether requests from Google's infrastructure succeed, nor whether Google has indexed the URLs.
- KoraTV already supplies result links in initial HTML. Before this release, Fraja supplied only loading placeholders and no initial match links.
- Both sites redirect HTTP to HTTPS. www.koratv.click resolves and redirects correctly. www.fraja.online returns DNS NXDOMAIN; the apex works. Fraja nameservers are dns1.registrar-servers.com and dns2.registrar-servers.com. GitHub Pages confirms fraja.online as its custom domain with HTTPS enforced.
- Search results queried during this audit did not establish indexing of either site. A third-party domain report is not Google's indexing status or a penalty diagnosis.

## Implemented Fraja changes

- Render the public match schedule into the published homepage, using the existing result/statistics pages. Match IDs are fetched from the public API with Fraja's Origin and intersected with generated pages. Cancelled fixtures are excluded. Channel and provider payloads are never rendered into the schedule.
- Preserve browser live updates and clear a prior-day static snapshot before hydration, using Morocco calendar dates.
- Put Fraja and its Arabic name consistently in homepage/news titles, headings, Open Graph and WebSite/Organization metadata, including domain and spelling alternatives.
- Add focused generation and regression tests; test no-JavaScript mobile/desktop output.
